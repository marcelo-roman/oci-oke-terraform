# Operations

## Authentication

The example uses a profile from `~/.oci/config`:

```bash
oci setup config
```

Prefer an API key profile over `oci session authenticate`: session tokens expire in about
an hour, and a node pool can take longer than that to come up when A1 capacity is short.

## Remote state

State holds OCIDs and the cluster CA. Keep it in Object Storage instead of on disk. With
Terraform 1.12 or newer, the native `oci` backend works with the same credentials:

```hcl
terraform {
  backend "oci" {
    bucket    = "terraform-state"
    namespace = "<object storage namespace>"
    key       = "oke/terraform.tfstate"
  }
}
```

Create a private, versioned bucket first:

```bash
oci os bucket create --name terraform-state --compartment-id <ocid> --versioning Enabled
oci os ns get
```

## Access the cluster

```bash
make kubeconfig
kubectl get nodes -o wide
```

`kubectl` authenticates with short-lived tokens generated by the OCI CLI, so the CLI must
be installed wherever `kubectl` runs.

## Exposing a Service

Services of type `LoadBalancer` create an OCI load balancer in the `lb` subnet. To stay on
the free shape:

```yaml
metadata:
  annotations:
    oci.oraclecloud.com/load-balancer-type: "lb"
    service.beta.kubernetes.io/oci-load-balancer-shape: "flexible"
    service.beta.kubernetes.io/oci-load-balancer-shape-flex-min: "10"
    service.beta.kubernetes.io/oci-load-balancer-shape-flex-max: "10"
```

## Scaling

Change `size` in `node_pools` and apply. Additional pools are additional map entries:

```hcl
node_pools = {
  arm = { size = 2, ocpus = 2, memory_in_gbs = 12 }
  x86 = { size = 1, shape = "VM.Standard.E5.Flex", ocpus = 1, memory_in_gbs = 8 }
}
```

## Kubernetes upgrades

With `kubernetes_version = null` the cluster follows the newest version OKE offers, which
means a plan can propose an upgrade whenever Oracle releases one. Pin the version to decide
when to upgrade:

1. Set `kubernetes_version` to the next minor version and apply. The control plane is
   upgraded first, then the node pool definition.
2. Existing nodes keep the old version until they are replaced. Cycle them from the
   console (*Node pool → Cycle nodes*) or with
   `oci ce node-pool update --node-pool-id <ocid> --node-pool-cycling-details '{"isNodeCyclingEnabled":true}'`.
3. Set `image_id` on the pool if you want a specific image instead of the newest match.

## Tear down

```bash
kubectl delete svc --all-namespaces --field-selector spec.type=LoadBalancer
make destroy
```

Load balancers and block volumes created from inside Kubernetes are not in the Terraform
state; delete them first or the subnets cannot be removed.
